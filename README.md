# Lighthouse 自动接单助手

当前版本：**0.7.123**（Chrome MV3 扩展）

[下载最新版 ZIP](https://github.com/ffffff9331/lighthouse-comment-runner/archive/refs/heads/main.zip) · [GitHub 仓库](https://github.com/ffffff9331/lighthouse-comment-runner)

用于扫描 Lighthouse 任务广场、接取符合条件的任务，在目标 X 推文页完成要求的互动与回复，再核对官方完成状态。

## 0.7.123 更新说明

- 支持普通转发任务：识别“转发互动／转发／转推／Repost／Retweet”，按原有最低赏金、档位、放号冷却和锁位规则接单；带评论或点赞的组合要求会保留，引用发帖、原创和关注任务仍不自动接取。
- 在 X 官方当前任务面板读取要求，只操作同一目标推文的原生“转帖 → 转帖确认”，确认已转发后进入原有验证流程；纯转发不会生成评论，已转发不会误点撤销。目标变化、人工停止、菜单不明或转发结果未确认时保留订单，不重复发送或提交。
- 旧版按“不支持转发”产生的永久忽略记录不再用于新版筛选；原记录保留，新版重新核对页面资格与要求，已回复历史和当前订单保护不受影响。
- 修复邀请单显示“任务完成，验证通过”后卡住：以同一已锁位弹窗的状态转换确认本单完成，点击“完成并关闭”，确认广场恢复后刷新并继续下一单。官网已确认完成时不再重复提交验证；关闭前若停止、切单或按钮变化，保留现场。
- 修复完成弹窗已关闭，但广场卡片中的“前往目标”文字被误判为详情仍打开、触发多余刷新的问题。

- 全量模式增加持久化的 20 分钟恢复计时。异常停止或后台重启不会丢失截止时间；到期自动重置旧流程、重新加载受控页面并恢复扫描，不以官方验证通过或“进行中 0 单”为恢复前提。

- 修复目标推文正文含“任务完成”等文字时干扰锁位、拒单识别的问题；真实订单状态仍以官方任务区域为准。

## 安装

1. 下载上面的 ZIP 并解压，把文件夹放在一个长期保留的位置。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的目录**，不要选择 ZIP 或外层空目录。
4. 打开并登录 [Lighthouse 任务广场](https://app.lhdao.top/campaigns) 和 X。
5. 点击扩展图标打开侧边栏，在设置中填写 API Key、模型及任务条件并保存。

本项目直接加载源码，不需要 npm 安装或构建。

## 更新

1. 先核对正在执行的订单，再停止当前运行。
2. 下载最新版 ZIP，把解压后的扩展文件覆盖到**原安装目录**。
3. 回到 `chrome://extensions`，点击此扩展卡片上的“重新加载”。
4. 刷新 Lighthouse 和 X 页面，确认扩展显示新版本后再启动。

本版应显示 **0.7.123**。确认新目录已正确加载后，删除旧版 ZIP 和重复解压目录，避免以后重载了错误的副本；不要删除 Chrome 当前加载的安装目录。

保持同一个扩展和安装目录，不建议卸载后重装。Key 和设置保存在 Chrome 的扩展数据中；只覆盖源码并重新加载会保留它们。

启动前会核对页面主脚本的版本和实例。扩展重载后若只剩监控脚本，最多补注入一次主脚本；仍未就绪时停止且不发送接单动作。已经发送但结果未知的接单不会因此重发。

## 配置

- AI 回复使用固定接口：`https://api.vayne.cc.cd/v1/responses`。填写该中转服务的 API Key，界面不提供接口地址和协议切换。
- 默认模型为 `gpt-6.1-sol`，模型名称可自行填写；是否可用以中转服务实际支持为准。已保存的模型不会被强制覆盖；清空模型输入框并保存即可使用新默认值。
- 系统提示词、最低赏金、每轮完成上限和接单尝试上限可在设置中调整。运行时间段功能当前关闭，不执行定时启停。
- 倒计时监控、监控赏金阈值和语音提醒可按需设置。
- 保存失败时，全量检测和单步流程不会继续；先根据侧栏错误修正配置再重试。

API Key 保存在本机的 `chrome.storage.local`，浏览器重启或扩展重新加载后仍保留。两个配置入口都使用密码输入框遮挡，存储访问限制为可信扩展上下文；**这不是加密存储**。

将 API Key 输入框清空后保存，会持续保留清空状态，不会从旧会话或旧设置恢复。停止运行不会清空 Key、其他设置或已完成历史。
旧版会话 Key 若已经因重启或重新加载而丢失，无法恢复，需要重新输入并保存一次。请勿把含有 Key 的截图、配置或日志提交到仓库。

## 使用

**全量检测**：扫描广场并筛选任务，打开详情、锁定席位、等待目标 X 页面，执行本单要求的互动与回复，提交任务组件，核对官方完成后返回广场继续扫描。

普通转发流程：**任务详情 → 点击锁定席位 → 等待抽签结果并确认本单锁位成功 → 前往 X 转发 → 按本单页面提交验证 → 确认本单完成 → 刷新广场继续下一单**。详情中的“抽签 · 锁定席位／前往 X 完成动作／回来提交验证”只是步骤说明，不作为锁位成功证据。转发后沿用 X 页“验证发奖”；若灯塔显示“任务执行与验证”，再回该弹窗点击“我已完成，开始验证”。任何提交动作本身都不计为任务完成。

运行中出现“专属任务邀请／接受并开始”弹窗时，会优先核对邀请的目标推文、任务类型和最低赏金，再接受并继续本单。已锁位的邀请直接接续；接受结果不明时保留订单，避免重复接取。明确过期且未接受的邀请会通过本弹窗的跳过/关闭入口退出；无可用入口时核对后刷新广场，继续寻找下一单。接受结果未知的邀请仍保留保护。禁用或目标不明的邀请不会点击接受；不支持的类型或赏金不足会跳过。已有订单、平台接单冷却和手动停止仍优先遵守。

邀请任务完整顺序：**接受专属任务邀请 → 点击“去完成任务” → 自动回复 → X 页“验证发奖” → 灯塔页“我已完成，开始验证” → 确认本单完成 → 点击“完成并关闭” → 刷新广场接下一单**。若官网提前返回本单完成结果，直接收尾，不重复提交验证。

邀请接取成功后，会从“任务执行与验证”弹窗核对锁位状态和目标推文，点击“去完成任务”进入 X。X 动作已确认完成、且开启自动发送和自动提交时，先按任务实际停留进度等待 X 页“验证发奖”可用并点击，再回到同一灯塔弹窗点击“我已完成，开始验证”，等待官方完成结果。执行页即使没有奖励金额或关闭按钮，也不会误读底层广场的资格限制。重复消息、人工停止、目标变化或回执丢失均有保护，点击验证本身不视为完成或到账。

**选中启动**：从侧栏倒计时列表选择任务后启动，仅执行所选的一单；正常放号倒计时会继续等待。

**单步流程**：点击某一步后，从该步继续执行后续步骤。接管旧流程前会核对取消回执；无法确认旧动作结果时，会保留订单等待核对。

**停止当前运行**：取消流程与步骤队列，清空本轮订单、待执行步骤、恢复状态、倒计时、统计及旧日志，仅保留停止记录；Key、设置和已完成回复历史保留。
停止后，刷新页面或后台唤醒不会自动恢复任务；需要再次明确点击全量检测、选中启动或单步按钮。
停止只能终止扩展后续动作，无法撤销已经发给平台的接单或评论，重新开始前应核对官网订单。

## 流程边界

- 没有可执行任务、下一批放号倒计时、平台冷却和额度限制，不能仅凭“没有继续点击”认定为插件卡死。
- 任务资格与按钮状态以网站为准；扩展不会绕过禁用按钮接单。
- 确认未接到单后刷新广场并重新读取任务，不给未抢到的任务增加本地去重；账户限速仍按平台提示等待。
- 收到本次、同一任务的明确拒单后，还要等“锁定席位”恢复可点击，才确认拒单。按钮仍显示禁用的“正在预定席位／正在锁定席位”时继续核对，不能直接当作失败重试。
- 已接单、评论结果未知或提交回执丢失时保留本单，不立即重发评论或重复提交；全量模式到达 20 分钟截止后按下面的恢复规则处理。
- 官网已锁位并给出匹配的目标链接时接续本单；页面跳到另一条推文不会被当成当前任务执行。
- X 页本单的官方“当前任务”面板显示“已完成”可以结束本单并返回广场，**不代表奖励已经到账**。奖励发放和实际到账以平台显示为准。
- 全量检测启动后启用独立的 20 分钟恢复闹钟，异常停止或后台重启后仍保留原截止时间；普通日志、阶段变化和重试不会续期。每次实际接单点击、本单成功完成后的下一轮扫描，以及超时恢复成功后，开始新的 20 分钟计时。选中单次和单步模式不启用此计时。
- 到期作废旧流程，取消旧动作并重新加载原任务 X 页和灯塔任务广场，然后恢复自动扫描；**不等待官网验证、订单完成回执或“进行中 0 单”**。取消消息无回执时通过重新加载页面终止旧脚本。平台会自动退掉超过 20 分钟未完成的订单，插件不额外发起退单，也不对超时旧单增加本地等待期。旧单及未知动作留存为恢复记录，不会因此补发评论、补交验证或把旧单计为完成；正常流程中的已有回复识别保持不变。页面加载或脚本连接失败时每分钟重试恢复。
- 手动停止、达到任务/尝试上限、计划休息和配置缺失会解除自动恢复。旧版本没有恢复计时记录的已停止流程不会自行启动；更新后启动一次全量检测即可启用。电脑休眠或 Chrome 关闭期间无法执行闹钟，恢复运行后按原截止时间检查。

侧栏提供运行日志、任务倒计时和回复记录。排查问题时，请同时核对任务身份、日志时间、官网当前订单及扩展版本。
