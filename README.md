# Lighthouse 自动接单助手

Chrome 扩展：在灯塔任务广场筛选任务，前往对应 X 推文完成评论、点赞或普通转发，核对结果后回广场继续。也支持这些动作的组合任务和专属邀请。

**当前正式版：0.7.135** · [下载 lighthouse.zip](https://github.com/ffffff9331/lighthouse-comment-runner/releases/latest/download/lighthouse.zip) · [版本历史](CHANGELOG.md)

## 安装和更新

**首次安装**

1. 下载并解压 `lighthouse.zip`，把解压出的文件夹放在长期保留的位置。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。
3. 登录 [灯塔任务广场](https://app.lhdao.top/campaigns) 和 X。点击扩展图标打开侧栏，在「设置」里填写 API Key，调整任务条件并保存。

**从旧版更新**

1. 先核对当前订单，处理完后点击「停止当前运行」。
2. 下载新版，解压并覆盖**原安装目录**。保留同一个扩展，无需卸载重装，这样能保留设置、Key 和历史记录。
3. 在 `chrome://extensions` 点击本扩展的「重新加载」，再刷新灯塔和 X 页面。确认 Chrome 显示正确版本后启动。旧 ZIP 和重复解压目录可清理，保留 Chrome 正在使用的目录。

扩展可直接加载，无需安装依赖或构建。

## 怎么运行

| 侧栏入口 | 用途 |
| --- | --- |
| 全量检测 | 自动扫描、接单和执行，确认本单完成后回广场继续。 |
| 选中启动 | 从倒计时列表选一项，只执行这一单；未放号时继续等待。 |
| 单步按钮 | 从指定步骤接着执行；旧动作结果不明时保留本单，先核对。 |
| 停止当前运行 | 取消后续操作、清空本轮状态；保留设置、回复和恢复记录。已发给平台的动作不会撤销，重新开始前先核对官网订单。 |

**普通任务：**打开详情 → 点击「锁定席位」→ 确认锁位成功 → 在 X 完成指定动作 → 按页面提交验证 → 确认本单完成并返回广场。抽签任务须等结果，详情页的步骤说明不代表锁位成功。若 X 页显示「验证发奖」，在 X 提交；若灯塔还显示「任务执行与验证」，再回该灯塔弹窗提交。纯转发不会生成评论；引用发帖、原创和关注任务不会自动接取。

**专属邀请：**接受邀请 → 点击「去完成任务」→ 在 X 完成指定动作 → 点击 X 页「验证发奖」→ 回灯塔点「我已完成，开始验证」→ 确认本单完成 → 点击「完成并关闭」→ 刷新广场接下一单。已取得同一单的官方完成结果时，直接收尾，不重复验证。

| 看到什么 | 怎么判断 |
| --- | --- |
| 暂无可做任务、放号倒计时、额度限制或平台冷却 | 属于等待或限制，先看侧栏日志，不必重载。 |
| 平台明确拒绝本次锁位 | 确认未接到单后回广场续扫；仅显示「正在锁定」时仍按结果未知处理。 |
| 已接单，但评论、验证或关闭的回执丢失 | 先核对同一订单。不立即重发评论、重复验证或接下一单。 |
| 官网显示本单「已完成」 | 表示任务可收尾。奖励是否到账以平台显示为准。 |
| 重载后提示脚本未就绪 | 确认加载的是原安装目录里的新版本，然后刷新灯塔和 X 页面。 |

## 卡单与自动恢复

- **只有「全量检测」有 20 分钟恢复计时。** 对每一单，插件在首次允许接单点击前保存截止时间；同一单的邀请确认、锁位、阶段切换和后台重启不会续期。
- 到期作废旧流程，重新加载受控页面并尝试恢复广场扫描。不等官网验证或「进行中 0 单」，不额外退单、不补发评论、不补交验证，也不会把超时计为完成。页面或脚本未就绪时按每分钟重试。
- 手动停止、运行达到上限或缺少配置时不会自动复活。电脑休眠或 Chrome 关闭期间不能执行恢复，重新运行后仍按原截止时间判断。
- 在**「记录 → 卡单与恢复」**查看最近 5 单的任务、卡住阶段、截止时间和恢复结果。重试更新原条目；普通等单不占名额。记录在停止和后台重启后仍保留。

## 设置与隐私

- 可设置回复模式、模型、提示词、最低赏金、每轮完成上限、接单尝试上限和语音提醒。选择「只填入」时，插件不会自动发送回复；未启用定时启停。
- AI 回复请求发送至 `https://api.vayne.cc.cd/v1/responses`，默认模型为 `gpt-6.1-sol`。保存失败时，先按侧栏提示修正配置再启动。
- API Key 保存在本机的 `chrome.storage.local`，仅可信扩展上下文可读；输入框用密码样式遮挡，**存储没有加密**。要移除 Key，请清空输入框并保存。
- 扩展需要访问灯塔和 X 页面，并使用标签页、存储、脚本注入、通知和定时器权限。请勿公开含 Key 的截图、配置或日志。
